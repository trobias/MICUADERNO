# Project documentation sync

When a requested project change materially alters architecture, setup, commands, verification, deployment, ownership, or agent workflow:

1. Locate the applicable `AGENTS.md` and `CLAUDE.md` files and respect their scope and existing content.
2. Update both with the same durable facts, expressed in the conventions of each file.
3. Keep instructions concise. Do not record transient implementation details, secrets, machine-specific paths, speculation, or a changelog of every edit.
4. Preserve user-authored rules and unrelated content. Never replace whole files for a small change.
5. If either file does not exist, explain the proposed location and ask before creating it.
6. Show exactly what documentation changed in the final handoff.

Documentation updates are part of the requested project change only when they are directly necessary to keep instructions accurate.
